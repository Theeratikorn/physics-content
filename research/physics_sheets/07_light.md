## 1. ธรรมชาติของแสง

### 💡 แสงคืออะไร?

**แสง** คือ คลื่นแม่เหล็กไฟฟ้าที่ตามนุษย์มองเห็นได้

### ⚡ ทฤษฎีคู่ของแสง

| ทฤษฎี | อธิบาย |
|--------|---------|
| **ทฤษฎีคลื่น** | แสงเป็นคลื่นขวาง, เดินทางเป็นเส้นตรง |
| **ทฤษฎีอนุภาค** | แสงเป็นอนุภาค (โฟตอน), อธิบายปรากฏการณ์บางอย่างได้ดี |

### 🌈 สเปกตรัมแสงที่มองเห็น

| สี | ความยาวคลื่น (nm) |
|----|---------------------|
| ม่วง | 380 - 450 |
| น้ำเงิน | 450 - 495 |
| เขียว | 495 - 570 |
| เหลือง | 570 - 590 |
| ส้ม | 590 - 620 |
| แดง | 620 - 700 |

### 📊 ความเร็วแสง

$$c = 3 \times 10^8 \text{ m/s}$$

## 2. การสะท้อนของแสง

### 🪞 กฎการสะท้อน

- มุมตกกระทบ = มุมสะท้อน
- รังสีตกกระทบ, รังสีสะท้อน, เส้นปกติ อยู่ในระนาบเดียวกัน

### 📐 การสะท้อนบนกระจกราบ

- ภาพจำลองอยู่หลังกระจก
- ระยะภาพจำลอง = ระยะวัตถุ
- ภาพกลับด้านซ้าย-ขวา

---

## 3. การหักเหของแสงและกฎของสเนลล์

### 📐 กฎเชนเซลล์ (Snell's Law)

$$n_1\sin\theta_1 = n_2\sin\theta_2$$

### 🔺 ดัชนีหักเห

$$n = \frac{c}{v} = \frac{\sin\theta_1}{\sin\theta_2}$$

### 📊 ดัชนีหักเหของสารต่างๆ

| สาร | ดัชนีหักเห (n) |
|------|------------------|
| สุญญากาศ | 1.0000 |
| อากาศ | 1.0003 |
| น้ำ | 1.333 |
| แก้ว (crown) | 1.52 |
| เพชร | 2.42 |

### 🔵 มุมวิกฤตและการสะท้อนกลับหมด

$$\sin\theta_c = \frac{n_2}{n_1}$$

**เงื่อนไข:**
1. แสงเดินจากตัวกลาง n มาก → n น้อย
2. มุมตกกระทบ > มุมวิกฤต

## 4. กระจกและเลนส์

### 🪞 กระจกราบ

$$\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i}$$

สำหรับกระจกราบ: f = ∞

### 🥁 กระจกเว้า (Concave Mirror)

| ตำแหน่งวัตถุ | ลักษณะภาพ |
|----------------|------------|
| ไกลกว่า C | จริง คว่ำ ขนาดเปลี่ยน |
| ที่ C | จริง คว่ำ ขนาดเท่า |
| ระหว่าง C กับ F | จริง คว่ำ ขนาดใหญ่ |
| ที่ F | ไม่เกิดภาพ |
| ระหว่าง F กับกระจก | เสมือน ตั้ง ขนาดใหญ่ |

### 🪞 กระจกนูน (Convex Mirror)

**ภาพที่ได้:** เสมือน ตั้ง ย่อ อยู่หลังกระจก

### 🔷 เลนส์นูน (Convex)

**เลนส์นูน:** รวมแสง → ภาพจริงหรือเสมือน

### 🔶 เลนส์เว้า (Concave)

**เลนส์เว้า:** กระจายแสง → ภาพเสมือน ย่อ ตั้ง

### 📐 สูตรกระจก/เลนส์

$$\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i}$$

$$M = \frac{h_i}{h_o} = -\frac{d_i}{d_o}$$

---

## 5. การเลี้ยวเบนและการแทรกสอดของแสง

### 🌀 การเลี้ยวเบน

เกิดเมื่อแสงผ่านช่องเปิดแคบ

### 🔬 การแทรกสอดจากสลิตคู่

**เงื่อนไข:**
- บรรทัดสร้าง: $$d\sin\theta = m\lambda$$
- บรรทัดทำลาย: $$d\sin\theta = (m + \frac{1}{2})\lambda$$

**บนจอ (L >> d):**
$$y_m = \frac{m\lambda L}{d}$$

---

## 6. สเปกตรัมและสี

### 🌈 การกระจายแสงขาว

แสงขาวผ่านปริซึม → แก้วแสงกระจายเป็นสเปกตรัม

**เหตุผล:** แต่ละสีมีดัชนีหักเหต่างกัน

### 🎨 การมองเห็นสี

- **แสงสีปฐมภูมิ (RGB):** แดง, เขียว, น้ำเงิน
- **การผสมแสง:** ผสมแสงเพิ่มกัน → ได้สีขาว
