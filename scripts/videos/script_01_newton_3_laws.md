## 🎬 SCENE 2: กฎข้อ 1 - ความเฉื่อย (2 นาที)

**[BROLL: ลูกบอลอยู่กับที่, รถเบรคกระทันหัน]**

### 🎯 กฎข้อ 1: "วัตถุจะรักษาสถานะเดิม ไม่เปลี่ยนแปลง จนกว่าจะมีแรงภายนอกมากระทำ"

เข้าใจง่ายๆ คือ:

> **"ถ้าไม่มีแรงมากระทำ สิ่งของจะอยู่นิ่งหรือเคลื่อนที่ตรงเสมอ"**

### 📌 ตัวอย่างในชีวิตจริง:

**[BROLL: รถตู้เบรคกระทันหัน]**

เคยไปรถตู้แล้วคนขับเบรคกระทันหันไหม?

ตัวเราจะ **"พุ่งไปข้างหน้า"** เพราะร่างกายเราติดอยู่กับสถานะเดิม (คือกำลังเคลื่อนที่ไปข้างหน้า)

นี่แหละคือ **"ความเฉื่อย"** หรือ **Inertia**

**[GFX: สูตร กฎข้อ 1]**

```
เมื่อ ΣF = 0  →  v = คงที่ (ไม่เปลี่ยน)
```

### 🎯 จำง่าย:
> **"ถ้าไม่มีแรงมาผลัก มันจะอยู่นิ่ง!"**

## 🎬 SCENE 3: กฎข้อ 2 - F=ma (2 นาที)

**[BROLL: ผลักของหนัก vs เบา]**

### 🎯 กฎข้อ 2: "แรงที่กระทำต่อวัตถุ = มวล × ความเร่ง"

**[GFX: สูตรใหญ่ๆ]**

```
F = ma
```

โดยที่:
- **F** = แรง (Force) หน่วย N (นิวตัน)
- **m** = มวล (Mass) หน่วย kg
- **a** = ความเร่ง (Acceleration) หน่วย m/s²

### 📌 ตัวอย่าง:

**[GFX: โจทย์]**
> มวล 10 kg ถูกแรงผลัก 50 N จงหาความเร่ง

**วิธีทำ:**
```
F = ma
50 = 10 × a
a = 50/10
a = 5 m/s²
```

### 🎯 จำง่าย:
> **"แรง = มวล × ความเร่ง"**
> มวลมาก = ต้องใช้แรงมากถึงจะขยับ!

## 🎬 SCENE 4: กฎข้อ 3 - ทำ-ถูกทำ (2 นาที)

**[BROLL: จรวด, พายุ, ว่ายน้ำ]**

### 🎯 กฎข้อ 3: "แรงที่กระทำต่อวัตถุ ย่อมได้รับแรงตอบโต้เท่ากันแต่ทิศตรงข้าม"

**[GFX: สูตร]**

```
F₁ = -F₂
```

### 📌 ตัวอย่างในชีวิตจริง:

**[BROLL: ว่ายน้ำ]**

เวลาว่ายน้ำ เราผลักน้ำไปข้างหลัง → น้ำผลักเราไปข้างหน้า

**[BROLL: จรวดขึ้นฟ้า]**

จรวดเผาไหม้เชื้อเพลิงผลักลงพื้นโลก → พื้นโลกผลักจรวดขึ้นฟ้า

### 🎯 จำง่าย:
> **"ทุกแรงมีแรงตอบโต้ ทิศตรงข้าม!"**
