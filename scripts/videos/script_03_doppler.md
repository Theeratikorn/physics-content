## 🎯 เป้าหมาย
- ผู้เรียนเข้าใจปรากฏการณ์ Doppler
- คำนวณความถี่ที่ผู้ฟังได้ยินได้

## ⏱️ เวลารวม: ~7-10 นาที

## 🎬 SCENE 1: บทนำ (30 วินาที)

**[BROLL: รถพยาบาลวิ่งผ่าน, เครื่องบินบินผ่าน]**

เคยสังเกตไหม?

เวลารถพยาบาลวิ่งมา เสียงไซเรนจะ **"แหลมขึ้น"** เมื่อเข้าใกล้
แล้วจะ **"ทุ้มลง"** เมื่อวิ่งห่างออกไป

**[GFX: เส้นคลื่นขยาย/หด]**

เหมือนกับเสียงเครื่องบินบินผ่านหัวเรา!

นี่คือปรากฏการณ์ที่เรียกว่า **"ปรากฏการณ์ดอปเปลอร์"** (Doppler Effect)

---

## 🎬 SCENE 2: อธิบายหลักการ (2 นาที)

**[GFX: แผนผังคลื่นเสียง]**

### 🎯 หลักการง่ายๆ:

คลื่นเสียงเดินทางในอากาศด้วยความเร็วคงที่ **~340 m/s**

แต่ถ้าแหล่งกำเนิดเสียง **เคลื่อนที่**:

**[GFX: ภาพเปรียบเทียบ]**

| กรณี | คลื่นด้านหน้า | คลื่นด้านหลัง |
|------|--------------|--------------|
| แหล่งเสียงเข้าใกล้ | **แน่นกว่า** → ความถี่สูงขึ้น | ห่างกว่า → ความถี่ต่ำลง |
| แหล่งเสียงห่างออก | ห่างกว่า → ความถี่ต่ำลง | **แน่นกว่า** → ความถี่สูงขึ้น |

### 📌 จำง่าย:
> **"เข้าใกล้ = แหลมขึ้น (ความถี่สูง)"**
> **"ห่างออก = ทุ้มลง (ความถี่ต่ำ)"**

---

## 🎬 SCENE 3: สูตร Doppler (2 นาที)

**[GFX: สูตรใหญ่ๆ]**

### 🎯 สูตรหลัก:

```
f' = f × (v ± v_Listener) / (v ∓ v_Source)
```

โดยที่:
- **f'** = ความถี่ที่ผู้ฟังได้ยิน
- **f** = ความถี่ต้นฉบับของแหล่งกำเนิด
- **v** = ความเร็วเสียงในอากาศ = **340 m/s**
- **v_Listener** = ความเร็วของผู้ฟัง
- **v_Source** = ความเร็วของแหล่งกำเนิดเสียง

### 📌 เลือกเครื่องหมาย:

**[GFX: ตาราง]**

| ทิศเคลื่อนที่ | ข้างบน (+) | ข้างล่าง (-) |
|--------------|-----------|-------------|
| ผู้ฟังเข้าใกล้แหล่งเสียง | v_Listener (+) | - |
| ผู้ฟังห่างจากแหล่งเสียง | - | v_Listener (-) |
| แหล่งเสียงเข้าใกล้ผู้ฟัง | - | v_Source (-) |
| แหล่งเสียงห่างจากผู้ฟัง | v_Source (+) | - |

## 🎬 SCENE 4: ตัวอย่างที่ 1 (2 นาที)

**[GFX: โจทย์]**

> รถพยาบาลไซเรนมีความถี่ 500 Hz
> วิ่งด้วยความเร็ว 30 m/s เข้าหาคนฟังที่อยู่นิ่ง
> ความเร็วเสียง = 340 m/s
> จงหาความถี่ที่คนฟังได้ยิน

**วิธีทำ:**

**[GFX: วาดภาพประกอบ]**

```
ข้อมูล:
f = 500 Hz
v = 340 m/s
v_Source = 30 m/s (เข้าใกล้ → ใช้ -)
v_Listener = 0 (อยู่นิ่ง)

ใช้สูตร:
f' = f × v / (v - v_Source)

f' = 500 × 340 / (340 - 30)
f' = 500 × 340 / 310
f' = 500 × 1.097
f' = 548.4 Hz
```

### 🎯 คำตอบ: **548.4 Hz** (แหลมขึ้น!)

---

## 🎬 SCENE 5: ตัวอย่างที่ 2 (2 นาที)

**[GFX: โจทย์]**

> นกหวีดความถี่ 600 Hz ตกจากเครื่องบิน
> เสียงเครื่องบินวิ่งด้วยความเร็ว 100 m/s
> ความเร็วเสียง = 340 m/s
> คนบนพื้นได้ยินเสียงความถี่เท่าไร?

**วิธีทำ:**

```
ข้อมูล:
f = 600 Hz
v = 340 m/s
v_Source = 100 m/s (ห่างออก → ใช้ +)
v_Listener = 0 (อยู่นิ่ง)

ใช้สูตร:
f' = f × v / (v + v_Source)

f' = 600 × 340 / (340 + 100)
f' = 600 × 340 / 440
f' = 600 × 0.773
f' = 463.6 Hz
```

### 🎯 คำตอบ: **463.6 Hz** (ทุ้มลง!)

## 🎬 SCENE 6: เทคนิคจำ (1 นาที)

**[GFX: สรุป]**

### 🎯 เทคนิคจำ:

> **"เข้าใกล้ ลบ ได้แหลม"**
> **"ห่างออก บวก ได้ทุ้ม"**

### 📌 จำภาพ:

**[GFX: รถพยาบาล + คนฟัง]**

- รถเข้ามา → ไซเรนแหลม
- รถผ่านไป → ไซเรนทุ้ม

## 🎬 SCENE 7: สรุป (30 วินาที)

**[GFX: ตารางสูตร]**

```
f' = f × (v ± v_L) / (v ∓ v_S)
```

| กรณี | สูตรย่อ |
|------|---------|
| แหล่งเสียงเข้าใกล้ | f' = f × v/(v-v_S) |
| แหล่งเสียงห่างออก | f' = f × v/(v+v_S) |
| ผู้ฟังเข้าใกล้ | f' = f × (v+v_L)/v |
| ผู้ฟังห่างออก | f' = f × (v-v_L)/v |
